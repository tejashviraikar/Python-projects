# 📚 Library Management System

A command-line Library Management System built using Python and Object-Oriented Programming (OOP). The application stores book data in a JSON file and allows users to manage books efficiently.

## Features

- Add Book
- View All Books
- Search Book by Title or ISBN
- Issue Book
- Return Book
- Store Data in JSON File
- Input Validation
- Object-Oriented Design

## Technologies Used

- Python 3
- JSON Module

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and Objects
- File Handling
- JSON Data Storage
- Functions
- Loops
- Exception Handling
