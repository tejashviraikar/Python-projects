# 🔐 Password Generator

A command-line Password Generator built using Python. Users can generate secure passwords by selecting the desired length and character types.

## Features

- Custom password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Random password generation
- Input validation

## Technologies Used

- Python 3
- random module
- string module

## Concepts Practiced

- Functions
- Loops
- If-Else Statements
- Exception Handling
- User Input
- Random Module
- String Module
