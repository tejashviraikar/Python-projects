# 🕒 Digital Clock

A simple Digital Clock built using Python and Tkinter. The application displays the current system time and updates every second.

## Features

- Real-time clock
- Updates every second
- Simple GUI using Tkinter
- Easy-to-read display

## Technologies Used

- Python 3
- Tkinter
- time module

## Concepts Practiced

- GUI Programming
- Event Loop
- Labels
- Functions
- Tkinter Widgets
