# 🌦️ Weather Application

A command-line Weather Application built using Python and the Open-Meteo API. No API key is required.

## Features

- Search weather by city
- Current temperature
- Humidity
- Wind speed
- Weather description
- Input validation
- Exception handling
- No API key required

## Technologies Used

- Python 3
- Requests Library
- Open-Meteo API

## Concepts Practiced

- REST API
- JSON Parsing
- Functions
- Exception Handling
- User Input
