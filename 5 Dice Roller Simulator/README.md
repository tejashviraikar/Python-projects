# 🎲 Dice Roller Simulator

A simple command-line Dice Roller Simulator built using Python. The user can roll one or more dice repeatedly until they choose to quit.

## Features

- Roll one or multiple dice
- Random dice values (1–6)
- Displays each die result
- Calculates the total
- Play repeatedly
- Input validation

## Technologies Used

- Python 3
- random module

## Concepts Practiced

- Functions
- Loops
- Lists
- Exception Handling
- Random Number Generation
