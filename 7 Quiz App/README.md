# 📝 Quiz Application

A command-line Quiz Application built using Python. The application presents multiple-choice questions, checks the user's answers, calculates the final score, and displays the correct answers.

## Features

- Multiple-choice questions
- Input validation
- Automatic score calculation
- Displays correct answers
- Play Again option
- Menu-driven command-line interface

## Technologies Used

- Python 3

## Concepts Practiced

- Lists
- Dictionaries
- Functions
- Loops
- If-Else Statements
- Exception Handling
- User Input
