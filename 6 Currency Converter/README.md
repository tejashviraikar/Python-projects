# 💱 Currency Converter

A command-line Currency Converter built using Python. It converts currencies using predefined exchange rates stored in a dictionary.

## Features

- Convert between multiple currencies
- Uses predefined exchange rates
- Input validation
- Menu-driven interface
- Supports multiple conversions

## Supported Currencies

- INR
- USD
- EUR
- GBP
- JPY
- AUD
- CAD

## Technologies Used

- Python 3

## Concepts Practiced

- Dictionaries
- Functions
- Loops
- Exception Handling
- User Input
