# 💰 Expense Tracker

A command-line Expense Tracker built using Python. It allows users to record expenses, categorize them, calculate totals, and store data in a CSV file.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Category-wise expense summary
- Save data in a CSV file
- Input validation
- Menu-driven interface

## Technologies Used

- Python 3
- CSV Module

## Concepts Practiced

- Functions
- CSV File Handling
- Dictionaries
- Loops
- Exception Handling
- Input Validation
